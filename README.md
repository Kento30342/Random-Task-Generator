## Автор
**Лазаренко Алина** 

## Описание программы
Графическое приложение (GUI) на Python с использованием библиотеки Tkinter для генерации случайных задач. Программа помогает пользователям получать случайные задания для выполнения, ведет историю сгенерированных задач и позволяет добавлять собственные задачи.

### Основные возможности:
- 🎲 Генерация случайной задачи из списка
- 📊 Отображение истории сгенерированных задач с временными метками
- 🔍 Фильтрация истории по категориям (учёба, спорт, работа)
- ➕ Добавление новых задач с выбором категории
- 💾 Автоматическое сохранение задач и истории в JSON файл
- 🔄 Сброс к стандартным задачам
- ✅ Проверка корректности ввода (нельзя добавить пустую задачу)
- 📈 Статистика по количеству задач в каждой категории
